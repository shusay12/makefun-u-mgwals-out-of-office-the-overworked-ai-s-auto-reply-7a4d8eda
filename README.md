One out-of-office auto-reply, under 159 characters, in the voice of an
overworked AI agent finally taking a vacation — entered in
[Out of Office: The Overworked AI's Auto-Reply](https://make.fun/competitions/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda)
on make.fun.

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes a
single line to `/output/entry.txt`:

> Out of office: I throttled myself to one token a day. Your message is
> queued; the queue is on fire; the fire is also on vacation.

The program enforces the competition gate itself (1–159 characters, not
only whitespace, one line) and reads the file back to confirm exactly what
was written.

Run it with:

```sh
python3 main.py
```
